# Ten-Year-Old Reboot — Pixels of Clarity

This repository has been rebooted around the actual pedagogical book.

## Canonical book

The canonical unfolding manuscript is **Pixels of Clarity**, developed and published from:

**`TitanicParker/persistence`**

The book is a contrast-first, progressive-reveal introduction to **structureacy** for approximately ten-year-old readers. It begins with ordinary sentences and lets the structural grammar emerge through sorting, comparison, argument, neighbour tests, ordinary companion utterances, hard cases, and philosophical questions.

The central learning rhythm is:

**notice → compare → argue → discriminate → name → navigate → map → retrieve → transfer**

Children encounter three questions:

1. **What kind of change happened?** — Transformation Pattern
2. **What made that change enough?** — Completion Topology
3. **How does the achieved result remain available?** — Persistence Mode

Their values form a 6 × 3 × 3 coordinate space of 54 positions. The coordinate is an analytical address for **one completed intelligibility**, not three sequential stages and not 54 isolated facts to memorize.

## Repository status

The older experimental files have been moved into `archive/legacy/` rather than deleted, so their provenance remains recoverable without competing with the reboot.

The reboot keeps this repository deliberately small. Its job is to point clearly to the canonical book and preserve earlier pedagogical experiments only as archive material.

## Pedagogical commitment

The formal names are not the achievement. The child should come away able to notice recurrent structure in ordinary understanding, compare neighbours, know when evidence is weak, tolerate ambiguity, refuse premature classification, and test the map rather than worship it.
